Questions, answered.

Does CODE SHIELD AI find every vulnerability?

No. No automated tool does. Each report lists the checks that ran and the checks that could not be completed, so you know what was covered.

Can I scan any website?

Only sites you own or have explicit permission to test. The scanner runs non-destructive checks and blocks local, private, and metadata addresses.

Are the fixes tested?

Suggested fixes are marked as untested unless an automated check has run against them. You always review a change before applying it.

Which languages are supported?

HTML, CSS, JavaScript, Python, PHP, Java, C and C++, SQL, and JSON. The Code Explainer focuses on HTML, CSS, and JavaScript.

Is my source code stored?

Scan metadata and findings are stored in your private history. Source code is only kept if you choose to save it, and you can delete it at any time.

Who is it for?

Developers, cybersecurity students, ethical hackers, and security professionals who want clear explanations along with the findings.
